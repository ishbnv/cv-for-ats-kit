# Project Kit «CV под вакансию» — как настроить за 5 минут

## Что это

Комплект для Claude Project: присылаете описание вакансии → получаете CV (PDF, одна страница, дизайн оригинала) и cover letter (PDF) или текст сообщения для Telegram, всё без следов LLM и только на подтверждённых фактах.

## Файлы: что и куда

Вставить в **Project instructions** (настройки проекта → «Set project instructions»):
- `PROJECT_PROMPT.md` — целиком, как есть.

Загрузить в **Project knowledge** (файлы проекта), ровно эти шесть:
1. `MASTER_FACTS.md` — факты о вас: единственный источник правды (46 КБ).
2. `STYLE_GUIDE.md` — чеклисты «чистки нейрослопа» и структура писем.
3. `render_cv.py` — рендер CV в PDF из JSON.
4. `render_letter.py` — рендер письма в PDF из JSON.
5. `EXAMPLES.md` — эталон: JSON, письмо, Telegram-сообщение, формат сводки.
6. `README.md` — этот файл (можно не загружать).

Ничего другого в проект не класть: старые PDF, master-HTML, markdown-мастера и заметки из Notion только размывают контекст и дают модели повод взять устаревшую цифру. Все шесть файлов вместе — около 75 КБ, они целиком помещаются в контекст, поиск по фрагментам не включается, поэтому контекст не теряется.

## Как пользоваться

1. Новый чат в проекте. Вставьте текст вакансии (или ссылку, если Claude может её открыть) — больше ничего писать не нужно.
2. Claude разбирает вакансию, принимает решения по умолчанию (MASTER_FACTS §11), собирает JSON, запускает скрипты, проверяет одну страницу и ключевые слова, прикладывает PDF и пишет сводку.
3. Вопрос вам он задаст только при блокере (страна вне списка, требование без единого факта в базе).
4. Если отклик через Telegram — вместо письма получите текст сообщения в чате.

Требование к аккаунту: в claude.ai должна быть включена возможность создавать файлы (Settings → Features → «Create and edit files»). Без неё Claude отдаст готовые JSON и текст — их можно отрендерить локально: `python3 render_cv.py cv.json out.pdf` (нужен только `pip install reportlab`).

## Как обновлять

- Новый факт, новая цифра, новый инструмент → в `MASTER_FACTS.md` (нужный раздел), заново загрузить файл в проект. Не сообщать факты в чате «на словах»: следующий чат их не увидит.
- Новое решение по умолчанию (например, «Alfa-Bank всегда нейтрально») → §11.
- Ловите след LLM, который прошёл → добавьте маркер в `STYLE_GUIDE.md` §2 или §3.
- Хотите поменять дизайн PDF → правьте только константы и стили в начале `render_cv.py`; логику автоподгона не трогайте.

## Почему так, а не иначе

- Один файл фактов вместо мастер-резюме с переключателями: модель не может «забыть» переключатель, и любое утверждение можно проверить по номеру раздела.
- Рендер детерминированным скриптом, а не свободной вёрсткой: одинаковый вид каждый раз, автоподгон в одну страницу, проверка ключевых слов и плейсхолдеров встроены.
- Самопроверка «злым редактором» прописана как обязательный шаг, потому что в проекте нет второго агента.
- Список «не заявлять» стоит выше требований вакансии: это единственная защита от правдоподобных выдумок.
